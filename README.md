# JavaScript 1 – Lessons (BE26)

This repository contains the code examples from the course *JavaScript 1* (spring 2026).

## How to use this repo

1. **Clone the repository once:**
   ```bash
   git clone git@github.com:kremer-webdev-courses/js1-vt26-be26.git
   cd js1-vt26-be26
   ```

2. **Switch to the branch for the lesson you want:**
   ```bash
   git branch -r                     # list all lessons
   git checkout lesson-05-functions  # example
   ```

Each `lesson-…` branch contains the code from one lesson: variables and scope, operators and conditions, loops, functions, array methods, the DOM and a TODO app, async/promises and fetch, a weather API app and an introduction to TypeScript.

The `exercise-weather-bugs` and `exercise-weather-solutions` branches contain a debugging exercise and its solution.
